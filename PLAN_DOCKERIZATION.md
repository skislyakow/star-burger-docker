## Важные заметки
- **Инфраструктурный репозиторий** - только docker-конфиги, код проекта в отдельном репозитории
- **Сборка через git clone в Dockerfile** - позволяет использовать один инфраструктурный репозиторий
- **Фронтенд и бэкенд в разных контейнерах** - обязательно
- **Node.js >= 17.6.0** для Parcel (используем Node 22)
- **На dev** - nginx в контейнере для удобства
- **На prod** - nginx внешний (общий на сервере)
- **collectstatic и migrate** - запускать явно
- **Media и БД** - volumes, не теряются при перезапуске/удалении контейнеров
- **docker-compose.yaml** должен быть в репозитории
